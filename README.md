# MONRE — кликабельный прототип

HTML/CSS/JS-прототип магазина по макету Figma «MONRE» (страница MAIN new). Без сборки и зависимостей.

Опубликованная версия: https://mlkdesign.github.io/MONRE/

## Как открыть

- Просто откройте `index.html` двойным кликом. Иконки встроены в CSS, скрипты обычные, поэтому всё работает и с `file://`.
- Или запустите локальный сервер: `node serve.js`, затем откройте http://localhost:5180.

Нужен интернет только для шрифтов Google Fonts (Jost, DM Sans, Cormorant Garamond).

## Что симулируется

- **Регистрация и вход фейковые.** Подходит любой email и любой пароль. Если email уже зарегистрирован в этом браузере, при входе с другим паролем покажется состояние «Wrong password», при повторной регистрации — «email already exists». Подсказка о слабом пароле показывается, но регистрацию не блокирует.
- **Заказ без оплаты.** На checkout подойдёт любая правдоподобная карта (например, 4242 4242 4242 4242, любой будущий срок, любой CVC). Карта `4000 0000 0000 0002` даёт состояние «Payment failed». Ещё можно выбрать Apple Pay или «On delivery».
- **Доставка за 30 секунд.** Статусы меняются так: Placed → Packed (8 с) → In transit (16 с) → Delivered (30 с). Каждая смена статуса приходит тостом, а трекер в кабинете (`Account → Orders & tracking`) обновляется в реальном времени, с обратным отсчётом и таймлайном в модалке «Track order». После доставки начисляются бонусы (5%).
- Если при гостевом заказе стоит галочка «Create account», аккаунт создаётся автоматически. На экране «Order placed» гость может сохранить заказ в аккаунт в один клик.
- **Промокод:** `MONRE10` даёт −10%, любой другой код показывает ошибку.
- Все данные (аккаунты, корзина, заказы, адреса, избранное, сертификаты, валюта) хранятся в `localStorage` этого браузера.

## Карта экранов

`#/index` (ссылка «Site map» в футере) — список всех экранов и состояний из макета со ссылками. Там же можно сбросить данные прототипа.

## Структура

```
index.html          оболочка
css/icons.css       иконки Phosphor из Figma (data-URI маски, цвет = currentColor)
css/base.css        токены, типографика, компоненты (кнопки, поля, тосты, модалки…)
css/layout.css      шапка, мега-меню, поиск, мини-корзина, футер, cookie-баннер
css/pages.css       стили страниц
js/data.js          каталог, наборы, категории, отзывы
js/store.js         состояние, корзина, скидки, фейковая авторизация, симуляция доставки
js/ui.js            общие компоненты, тосты, модалки, поповеры, шапка/футер
js/pages-*.js       страницы
js/app.js           роутер (hash), делегирование событий, тикер доставки
assets/img, icons   ассеты, выгруженные из Figma (сжаты в JPEG/WebP)
```

## Отличия от макета

- В части модалок и тостов макета стояли плейсхолдеры («Modal body — replace with…», «Something went wrong» на всех ошибках). В прототипе там тексты по смыслу, а вид взят из компонентов библиотеки (Modal Shell, Toast, Notice).
- Меню пользователя и cookie-баннер в макете пустые. Они сделаны в стилистике системы (dropdown и Notice).
- Ошибки в формах раздвигают контент, а не накладываются на соседние поля, как в части фреймов макета.
- Языки, кроме English, переключают только подпись (тексты прототипа на английском, как в макете). Валюта пересчитывает все цены.
